# Clue Combat Helper

A RuneLite plugin that shows combat advice for treasure trail clue scroll encounters.

## Features

- Detects coordinate, emote, and hot/cold clues that trigger combat encounters
- Shows the monster you'll face, gear, and what to bring
- Reads the clue's enemy field to show the exact enemy or "either/or" when random
- Wilderness warnings with red text and risk-appropriate gear suggestions
- Clue box reminders for wilderness encounters

## Supported Encounters

- Saradomin Wizard
- Zamorak Wizard
- Double Agents
- Brassican Mage and Ancient Wizards
- Armadylean and Bandosian Guards
